# Celest Learn

Practical guidance for understanding, building, and operating AI agents across Celest and Microsoft 365.

- [Read Celest Learn](https://celest.dev/learn/)
- Connect your MCP client to `https://celest.dev/learn/mcp`
- [Suggest an improvement](https://github.com/celest-dev/learn/issues/new?template=learn-feedback.yml)

The Learn MCP finds public guidance on `celest.dev` and `learn.microsoft.com` through Bing. Use `ask` to find cited sources, `read` to open a source as Markdown, and `similar` to explore the curated Celest reading list. It cannot access your tenant or private records.

## Help improve Learn

This is the public feedback home for Celest Learn. We welcome corrections, missing topics, source suggestions, and reports of unhelpful search results. Open an issue with what you expected to find; include the article URL, your complete question, and any relevant public source when available. You do not need a proposed fix to participate.

Please leave out credentials, private tenant data, and customer content. We review suggestions before changing published guidance.

GitHub requires an account to submit an issue. Prefer email? Reach us at [founders@celest.dev](mailto:founders@celest.dev?subject=Celest%20Learn%20feedback).

This repository hosts feedback and contribution templates. The published guidance and MCP service are at [celest.dev/learn](https://celest.dev/learn/).
